# 03. UI / UX Specification

화면 구성과 시각 언어는 `assets/design/mockups/`의 목업 8장을 따른다(DECISIONS D-018).
목업은 배치·색·형태의 기준이고, 글자·수치·콘텐츠 이름은 게임 데이터와 로컬라이제이션에서 온다.

## 1. Principles
- 자연 화면 70~80% 유지
- HUD는 필요할 때만 보이고 유휴 시 자동 숨김
- 중요 행동은 한 손 엄지 범위 우선
- **알림 점**: "아직 보지 않은 새 것"이 있을 때만 버튼 오른쪽 위에 작은 점 하나. 숫자 카운트·깜빡임·중첩 금지.
  점은 모양으로도 구분되고(색만이 아님), 버튼 툴팁에 이유를 적는다. 예: 도감(새로 만난 물고기), 복원(복원 가능)
- 보상 팝업 중첩 금지
- 색상만으로 상태를 전달하지 않음

## 2. Navigation
```text
World
├─ Journal  (전체 / 연못 / 계곡 / 강 / 바다 / 특수)
├─ Gear     (낚싯대 / 미끼 / 가방 / 악세서리)
├─ Camp     (꾸미기 / 배치 / 가구 / 장식)
├─ Region Map (상단 지역 표시를 눌러 연다)
└─ Settings
```
도감 탭은 목업의 "민물/호수/계곡/특수" 자리를 게임의 지역 묶음으로 채운다: 목업의 분류는 이 게임의 지역과 맞지 않기 때문이다(D-018).

## 3. Main World (mockup 01)
상단 (어두운 반투명 알약):
- 좌: 산 아이콘 · 지역명 │ 시계(HH:MM) │ 날씨 아이콘 · 날씨
- 우: 물결(Ripple) · 추억(Memory) 재화, 원형 설정 버튼. 그 아래 원형 물멍 버튼
- 좁은 화면에서는 재화 이름 → 날씨 이름 순으로 글자를 숨기고 아이콘은 남긴다. 지역명 말줄임은 마지막 수단

하단 (크림 카드 + 나무 판):
- 도감 · 장비 · **낚시**(나무 판에 물결 띠, 가장 큼) · 캠프
- 복원은 오른쪽 위 원형 버튼(물멍 아래)으로, 복원할 수 있으면 점이 붙고 이름이 "복원 가능"으로 바뀐다

월드 구도: 왼쪽 아래 부두와 의자에 앉은 낚시꾼, 왼쪽 위 캠프 터(텐트·의자·랜턴·상자), 오른쪽 위 폭포와 바위,
오른쪽 연잎, 위쪽 나무 그늘, 아래쪽 꽃과 덤불. 낚시꾼은 연못 안쪽(오른쪽 아래)을 향해 던진다.

5초 입력 없음 → HUD fade. 화면 터치 → HUD 복귀(그 터치는 던지기로 처리하지 않음).

## 4. Fishing UX (mockup 02)
### Aim
Drag gesture + landing indicator. 과도한 trajectory UI 없음. 낚시꾼 정면 ±80° 안으로만 던진다.

### Wait
최소 UI. 찌와 환경이 주인공. 하단은 낚시 줄로 바뀐다: 취소 · 원형 행동 버튼 · 물고기 도감, 그 아래 한 줄 안내.

### Bite / Hook
찌 옆에 "입질!" 말풍선과 반짝 표시, 낚시꾼이 놀라는 자세. 원형 버튼이 "챔질"이 된다.
접근성 Visual Bite Cue는 찌 둘레에 맥박 치는 고리를 더한다. 실패 시 비난 문구 금지.

### Fight
- 장력 막대: 양 끝 갈색 → 주황 → 안전 구간 청록·초록, 흰 괄호로 안전 구간 표시, 물고기가 올라탄 표식이 현재 장력
- 막대 아래 "약함 · (상태 단어) · 강함" — 위치와 단어가 같은 정보를 준다(색만이 아님). High Contrast는 위험 구간에 빗금
- 원형 "릴링" 버튼 둘레의 금색 고리가 끌어올린 정도
- 한 손 입력. Reduced Motion 사용 시 camera motion 제거
- 싸움 중에는 도감 버튼을 막는다(물고기를 두고 떠나지 않게)

### Inspect (mockup 03)
흐린 연못 위에 결과 화면. 상태 표시줄은 남긴다.
- 처음 발견이면 월계수 장식과 "새로운 물고기를 낚았어요!"
- 큰 물고기 그림과 희귀도 쪽지(일반·고급·희귀·특별·전설 + 한 줄)
- 나무 액자 속 종이 카드: 이름, 크기, 만난 횟수, 관찰형 한 줄, 발견한 장소·시간
- 버튼: **방생**(놓아주고 머문다) · **기록**(도감에서 보기) · **다시 낚시**(놓아주고 바로 다시 던진다, 나무 판으로 강조)

세 버튼 모두 놓아주는 흐름이며 판매·보관 버튼은 없다(GDD §11). 포획 즉시 도감에 기록된다(D-010).

## 5. Journal (mockup 04)
- 나무 간판 제목, 뒤로 버튼, "발견한 물고기 n/전체"
- 왼쪽 수첩: 2열 물고기 카드. 처음 보는 종은 실루엣과 "???", 모든 정보가 열린 종은 왕관, 만났지만 아직 안 본 종은 NEW
- 오른쪽 페이지: 이름·한 줄, 그림, 처음 만난 날 / 발견한 날의 날씨 / 서식지 / 출현 시간 / 최대 크기 / 만난 횟수, 주요 서식지 카드
- 잠긴 정보는 "n번 만나면 알 수 있어요"로 언제 열리는지 알려 준다(무지함을 벌주지 않음)
- 정렬: 획득 순 / 이름 순 / 크기 순 (만난 종이 먼저)
- 하단 내비게이션은 도감 위에서도 보인다(낚시를 누르면 도감을 닫고 던진다)

## 5.1 Region Map (mockup 07)
상단 지역 알약을 누르면 열린다. 바다 위 섬 다섯 개와 점선 길, 섬마다 크림 이름표(아이콘·이름)와 "물고기 만난 수/전체" 알약.
지금 있는 섬은 빛나는 테두리, 잠긴 섬은 어둡게 + 자물쇠. 이름표를 누르면:
- 지금 섬: "지금 ○○에 있어요"
- 잠긴 섬: 실제 해금 조건과 지금 진행(복원 단계, 만난 종 수)
- 열렸지만 아직 풍경이 없는 섬: 다음 업데이트에서 만날 수 있다고 알린다(P2에서 이동이 열린다)

## 6. Restoration
업그레이드 버튼을 누르면:
1. 요구 조건 표시
2. 승인
3. 월드 변화 카메라 연출 2~4초
4. 새 생물/오브젝트 Highlight
긴 보상 팝업 금지.

## 7. Camp (mockup 06)
Drag-to-place는 선택. 초기 버전은 slot/anchor 방식으로 모바일 조작 복잡도를 낮춘다.
월드가 그대로 보이고 카메라가 캠프 터로 다가간다(Reduced Motion이면 바로). 자리마다 점선 마름모, 고른 자리에 회전·확인·치우기
원형 버튼. 하단 시트: 꾸미기(전체)/배치(놓인 것)/가구/장식 탭과 아이템 카드, "완료" 나무 버튼.
가진 꾸밈을 누르면 고른 자리에 바로 놓이고, 없는 꾸밈은 확인 버튼에 값이 붙어 누르면 사서 놓는다.
아직 보지 않은 꾸밈이 생기면 캠프 버튼에 점이 붙는다.

## 8. Water-Mind Mode (mockup 08)
진입 시 HUD 전부 제거, 가벼운 오버레이만 남긴다:
- 좌상단 "물멍 모드" 알약 — 누르면 나간다
- 우상단 "UI 숨기기" — 오버레이를 숨긴다. 물을 누르면 다시 보인다. 몇 초 그대로 두면 스스로 숨는다
- 하단 원형 버튼: 저장(장면 사진) · 시간(새벽/낮/해질녘/밤 미리보기) · 날씨(지역 날씨 미리보기) · BGM(소리 섞기)
- 시간·날씨는 **화면에만** 보이는 미리보기다. 실제 시계·날씨·낚시 판정은 그대로 흐르고, 나가면 원래대로 돌아온다

Burn-in/배터리 고려:
- optional dim after N minutes
- battery saver 안내는 1회만

## 10. Responsive
Phone portrait = 기준.
Tablet = 월드 가시 영역 확장(월드는 설계 영역 밖까지 그려진다, layout bleed).
Desktop landscape = 중앙 디오라마 + side utility panels 옵션.

단순 9:16 확대 금지. 전체 화면 패널(포획 결과·도감·장비·캠프·지도)은 720 px 폭 안에 들어가야 한다(테스트로 확인).

## 11. Touch Targets
내부 기준 48dp급 이상. 목업의 작은 알약·원형 버튼은 그림만 작고 누르는 영역은 48dp를 유지한다(InsetStyle).
아이콘 단독 버튼에는 accessibility label(tooltip).

## 12. Copy Tone
짧고 관찰형.
금지: "실패!", "놓쳤습니다!", "연속 보상 손실!"
권장: "물속으로 돌아갔어요.", "다시 가까이 올지도 몰라요."

## 13. Visual Language
| 요소 | 모양 | 쓰임 |
|---|---|---|
| 크림 카드 | `#f4ecdd` 바탕, `#d6c3a0` 테두리, 둥근 모서리, 옅은 그림자, 진갈색 글자 `#4a3826` | 기본 버튼·패널·카드 |
| 나무 판 | `#8a5a36` 바탕, 나뭇결, 위쪽 밝은 선 | 화면의 핵심 행동(낚시·다시 낚시·완료), 제목 간판 |
| 숲 초록 | `#627d4c` | 선택됨(탭·장착·확인) |
| 어두운 알약 | 반투명 검정 62%, 크림 테두리, 크림 글자 | 풍경 위 상태 표시·안내·원형 버튼 |
| 금색 | `#e3b24f` | 포커스 링, 왕관, 진행 고리 |
| 알림 | `#e2683f` 점 / NEW 뱃지 | 아직 안 본 새 것 |

아이콘은 단색 실루엣(`tools/generate_ui_icons.py`)이고 버튼 색에 맞춰 칠한다. 정식 아이콘이 오면 같은 이름으로 교체한다.
