# 11. Production Risk Register

| Risk | Severity | Early Signal | Mitigation |
|---|---|---|---|
| 낚시 반복 피로 | Critical | 10분 내 지루함 | wait ambient events, fishing timing A/B playtest |
| 생태계 변화 체감 부족 | Critical | 방생 후 변화 인지 못함 | First Wow scripted, visible agent/presentation 강화 |
| 콘텐츠 제작량 폭증 | High | fish 1종 제작 시간이 계획 초과 | shared behavior/material pipeline, content budget lock |
| 모바일 발열 | High | 물멍 10분 후 thermal throttling | 30FPS/battery saver/AI tick tiers |
| 저장 손상 | Critical | force-close recovery 실패 | atomic save + rotating backup + migration tests |
| 물 셰이더 성능 | High | low/mid GPU frame drop | compatibility renderer, simple water tiers |
| UI가 풍경을 가림 | Medium | screenshot에서 HUD 비중 과다 | idle auto-hide, 70~80% world rule |
| 희귀어 RNG 스트레스 | High | 조건을 알아도 장시간 미획득 | hint + pity + deterministic scripted moments |
| 상용 전환율 부족 | Medium | 무료 지역 만족은 높으나 구매 의사 낮음 | paywall timing/product messaging playtest |
| 범위 팽창 | High | crafting/social/ranking 요청 증가 | North Star gate + explicit non-goals |
| 아트 일관성 부족 | High | fish/region 스타일 편차 | art bible + review checklist |
| 스토어 정책 변경 | Medium | 제출 직전 요구사항 불일치 | release 직전 공식 문서 재검증 |
